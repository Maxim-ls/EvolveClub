# Reference HTML

Эти файлы оставлены только как архивные примеры старой верстки:

- `country-example.html`
- `hotel-example.html`
- `tour-example.html`

Они не участвуют в сборке сайта и не должны редактироваться как рабочие страницы.

Рабочий контент находится в:

- `content/countries`
- `content/hotels`
- `content/tours`

Рабочие шаблоны:

- `country-page.njk`
- `hotel-page.njk`
- `tour-page.njk`
