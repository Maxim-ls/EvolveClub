# Настройка отправки заявок

Формы сайта отправляют заявки в файл `/send-request.php`.

## 1. Конфиг почты на Beget

Создайте файл выше каталога `public_html`:

```text
/home/e/evolveclub/evolveclub/request-mail-config.php
```

Содержимое:

```php
<?php

return [
    'mail_to' => 'mail@example.com',
    'mail_from' => 'no-reply@evolveclub.ru',
    'subject_prefix' => 'EvolveClub',
];
```

`mail_to` - куда приходят заявки.

`mail_from` - технический отправитель. Лучше использовать адрес на домене сайта, например `no-reply@evolveclub.ru`.

## 2. Что отправляется

В письмо попадают:

- имя;
- контакт;
- направление / даты / отель, если поле есть в форме;
- комментарий;
- заголовок страницы;
- URL страницы;
- IP и User-Agent.

## 3. Проверка

После деплоя откройте сайт, отправьте тестовую заявку и проверьте почту.

Если письмо не пришло, проверьте:

- создан ли файл `request-mail-config.php`;
- правильно ли указан `mail_to`;
- включена ли почта домена в Beget;
- не попало ли письмо в спам.
